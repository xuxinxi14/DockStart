# GitHub 发布说明维护

v1.0.4 的具体说明已经整理为 [v1.0.4 发布说明](v1_0_4_release_notes.md)，不要复制旧版测试数量、哈希或稳定版承诺。

## 发布前填齐

1. 应用版本、档位、系统支持与真实成熟度。
2. 明确的源码 SHA 与标签对应关系；若安装包来自 dirty 构建，保留原候选来源，不能暗示完全可重建。
3. 实际将提供的每个资产的文件名、大小、SHA256 和签名状态。
4. 当前包对应的验证结果与未完成项，区分源码测试、MSI 内容提取、EXE 安装/卸载和科学协议验收。
5. 工具、输入格式、联网边界、已知限制和数据备份说明。
6. 下载后的快速开始、在线章节和反馈入口。
7. Docking score 仅供结构结合趋势参考，不能替代实验验证。

## 原则

- 候选/试用版本标记为 prerelease，不因“上传成功”自动升级稳定版。
- 只列实际上传的文件，不把本地候选描述成可下载资产。
- SHA256 从最终文件计算，上传后再次与 GitHub asset digest 对照。
- 已发布文件不在同名下静默替换；明确记录来源、修正时间和变更范围。
- 历史 tag 若有误，先核对原 SHA、正确提交、资产身份与公开说明，再做引用修正；不能顺手改变应用算法或包版本。

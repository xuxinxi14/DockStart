# DockStart v0.13.8 本地 GUI 候选包构建记录

日期：2026-08-03

## 候选包范围

本次仅生成 Windows x64 Assisted 候选包。该版本随附 Python、RDKit、Meeko 与 AutoDock Vina，适合复测受体/配体准备、批量配体、大环配体和 AutoGrid4 配置入口。

本记录不是公开 Release 声明。本轮按要求未执行完整发布前测试、真实安装后回归和卸载残留检查，因此产物仅供人工验收，`publishable = false`。

## 本轮修复

- 修复受体结构审查区在窄窗口中的横向溢出和内容遮挡。
- 批量配体准备页可列出并切换全部候选，不再只预览一个配体；保留来源文件名或化学标识，不再统一显示为 `ligand.pdbqt`。
- 批量查看器增加目录穿越、绝对路径、符号链接、扩展名和 SHA256 校验。
- 大环配体准备改为明确的分析、选择、确认和转换流程；清理浏览器原生单选框高亮与内部多余圆角。
- 工具链页增加 AutoGrid4 检测与配置入口；展开详情移出卡片网格，避免卡片高度和右栏布局跳动。

# DockStart v0.14.0 本地 GUI 候选包构建记录

日期：2026-08-04

## 候选包范围

本次仅生成 Windows x64 Assisted 候选包。v0.14.0 在既有标准 AutoDock4 maps 工作流上补齐有限柔性单配体、刚性串行批量和刚性双配体共同对接。

本记录不是公开 Release 声明。本轮按要求只执行与新增能力直接相关的回归、生产构建和安装器生成；未执行全部后端/Rust 测试、真实安装后回归或卸载残留检查，因此产物只供本地人工验收。

## 本轮能力

- 有限柔性标准 AD4：maps 绑定柔性准备记录中的刚性分量，run 同时冻结并加载匹配的柔性侧链 PDBQT。
- 串行批量标准 AD4：一组 maps 在建队时冻结并校验，配体逐项独立执行、恢复、汇总和归档。
- 双配体共同标准 AD4：两个有序配体在同一次 `--ligand` 联合搜索中使用 `--maps ... --scoring ad4`，结果只表达联合评分。
- GUI 协议门禁允许上述标准 AD4 路径，同时继续阻止 AD4Zn、水合 AD4、评价任务或不兼容柔性/批量组合被静默混用。

## P0：30 分钟界面与主流程冒烟

### A. 启动、导航与等待反馈

- [ ] **P0-01** 启动后默认进入“帮助”页；顶部、侧栏、底栏均无空白、重叠或截断。
- [ ] **P0-02** 依次点击“结果 → 运行工作台 → 结构获取与转换 → 项目”，即使未创建项目也不会卡死；每页给出可理解的空状态或返回路径。
- [ ] **P0-03** 创建项目后故意不按顺序点击四个主要步骤，页面可正常切换，程序无假死、无限加载或空白页。
- [ ] **P0-04** 切换亮色/暗色主题；文字、边框、表格值、禁用按钮和状态徽标均清晰可读。
- [ ] **P0-05** 在 1366×768、Windows 100% 和 125% 缩放下检查所有主页面；无横向滚动、右栏遮挡、底部操作栏盖住内容。
- [ ] **P0-06** 用 Tab 键遍历顶部、侧栏和当前页主要操作；焦点框可见，“跳到主要内容”可用。
- [ ] **P0-07** 执行受体/配体导入、在线搜索、转换和重新检测；操作期间出现明确加载窗口，完成或失败后会关闭。
- [ ] **P0-08** 加载期间连续点击同一按钮不会重复启动任务；界面说明正在处理，而不是只把按钮变灰。
- [ ] **P0-09** 触发一个可恢复错误（例如选择错误格式文件）；中文错误包含原因和下一步，关闭错误后仍能继续操作。

### B. 最小 Vina 闭环

- [ ] **P0-10** 创建新项目，分别导入已准备的 receptor PDBQT 和一个 ligand PDBQT；状态卡正确显示文件名和“PDBQT 已准备”。
- [ ] **P0-11** 在同一 3D 视图显示受体、配体和 Box；六个 Box 数值可编辑、保存、重开项目后保持一致。
- [ ] **P0-12** 保存一组固定 Vina 参数并重新检查；运行前检查逐项显示受体、配体、Box、Vina 状态。
- [ ] **P0-13** 创建并完成一个小型 `vina` 全局对接；运行中有进度/阶段反馈，完成后能进入结果页。
- [ ] **P0-14** 结果页切换至少两个 Mode；3D 构象、评分行和右侧所选构象同步变化。
- [ ] **P0-15** 展开“完整 metadata 快照”；3D 区域和右侧构象列表位置不变，右栏无任何部分被遮挡。
- [ ] **P0-16** 在亮色主题查看“运行日志与文件”；文件名、路径和值均可读，不出现白字白底。
- [ ] **P0-17** 打开“分析报告”，生成 Markdown；状态从待导出变为已导出，报告路径、参数、评分和科学免责声明正确。
- [ ] **P0-18** 完全退出并重开 DockStart，再打开项目；历史 run、分数、构象和报告仍能读取，未自动重跑。

## P1：结构获取、准备与评价模式

### C. 在线检索和本地准备

- [ ] **P1-01** 用 PDB ID 搜索 RCSB；结果区显示多个候选、分辨率/方法等元数据，搜索不会自动覆盖项目文件。
- [ ] **P1-02** 展开受体候选详情并打开临时 3D 预览；确认后“选择并准备”才写入项目并生成 PDBQT。
- [ ] **P1-03** 用名称搜索 PubChem；结果区显示多个候选、CID、分子式和分子量，可先预览再选择。
- [ ] **P1-04** Assisted 环境从 PDB/mmCIF 和 SDF/MOL 自动准备 PDBQT；工具链页能正确识别随附 Meeko，不显示“检测错误/未获取版本”。
- [ ] **P1-05** 打开结构复核信息；来源于原始 PDB/mmCIF 的链、异源物、残基异常等信息可读取，最终 PDBQT 的原子/坐标事实也可读取，两类来源不会混写。
- [ ] **P1-06** 检查受体/配体摘要卡；同一事实保持单行或协调网格，不出现每个数值旁重复的“最终 PDBQT”徽标。
- [ ] **P1-07** 用 Basic 环境尝试 raw→PDBQT；界面明确说明 RDKit/Meeko 不可用，但已准备 PDBQT 导入仍可继续。

### D. 仅评分、局部优化和高级参数

- [ ] **P1-08** 切换“仅评分”；界面要求在同场 3D 中确认输入姿势，未确认时运行被阻止。
- [ ] **P1-09** 确认姿势后替换受体或配体；原确认自动失效，不能沿用旧哈希启动新 run。
- [ ] **P1-10** 完成 `score_only`；结果和报告标明“姿势评价”，不声称完成全局搜索，也不生成新构象输出。
- [ ] **P1-11** 完成 `local_only`；结果显示输入评分、优化后评分、差值、几何位移和两个阶段的日志。
- [ ] **P1-12** 检查高级参数 `max_evals`、`min_rmsd`、`spacing`、`verbosity`、`no_refine`、`force_even_voxels`、`unbound_energy`；只在适用协议/任务中显示并进入命令预览。
- [ ] **P1-13** 输入非法高级参数（负值、非数字、越界）；保存前阻止并指出具体字段，旧有效配置不被覆盖。

## P1：多配体、批量和柔性受体

### E. 多文件导入与运行模式

- [ ] **P1-14** 在配体 PDBQT 导入入口一次选择多个文件；不再限制为 1 个，导入后默认进入“串行批量筛选”。
- [ ] **P1-15** 单配体与批量筛选是两个独立界面；批量页仍保留受体 3D、Box 和 Vina 参数，不是只有队列导入卡。
- [ ] **P1-16** 从多个 PDBQT 创建串行队列，完成至少 3 项；队列状态、失败重试、Top N 和全量 CSV 正确。
- [ ] **P1-17** 运行中请求安全取消；当前项结束后不再启动新项。退出、重开项目并恢复后，已完成项不会重跑。
- [ ] **P1-18** 导入一个无效配体；失败项保留错误与尝试记录，不阻塞后续有效配体，Summary/Top N 不把失败项伪装为成功。
- [ ] **P1-19** 归档终态批量任务并创建新队列；旧归档可查看/比较/导出，项目输入和既有 run 不被删除。
- [ ] **P1-20** 若当前 Vina 支持多配体命令，进入“多配体共同对接”；必须明确显示两个成员的固定顺序、联合 Mode 和联合评分，不能拆成成员 affinity。
- [ ] **P1-21** 多配体共同对接结果可在 3D 中同时开关两个成员；报告保留成员顺序和输入哈希。

### F. 有限柔性侧链

- [ ] **P1-22** “刚性受体 / 有限柔性”按钮与内容边缘留白一致；内部直角分隔线没有多余圆角，说明文字只面向用户。
- [ ] **P1-23** 点击“在 3D 中点选”后直接进入全屏受体预览；页面底部中央显示已选数量和“选择完成”。
- [ ] **P1-24** 点选/取消至少两个合法残基；选择状态和文本选择器同步，点击“选择完成”退出全屏并保留选择。
- [ ] **P1-25** 测试插入码、altloc、无效链、配体对象、水分子和不存在残基；准备前被安全拒绝并显示具体原因。
- [ ] **P1-26** Assisted 环境完成 rigid/flex/JSON 三件套准备和一次柔性 Vina run；命令、metadata 和报告均记录柔性输入。
- [ ] **P1-27** 准备失败或异常残基未确认时，项目继续使用上一份有效刚性/柔性文件，不发布半成品。

## P2：高级与 Experimental 科学协议

这些项需要对应真实工具、合法输入和较长运行时间。缺少前置条件时记为“阻塞”，不要伪造通过。

### G. 大环配体

- [ ] **P2-01** 用 BACE_1 输入进入大环准备；显示候选断环、人工选择和刚性大环选项，不静默自动发布。
- [ ] **P2-02** 选择候选并完成准备；PDBQT、候选身份、断环、G* 数量、工具版本和输入哈希进入记录。
- [ ] **P2-03** 完成一次大环 run 并导出 SDF；每个 pose 无 G*，重原子数、连接、形式电荷和立体信息可被 RDKit 读取。
- [ ] **P2-04** 移除拓扑/原子映射证据后再次导出；必须 fail closed，不能猜测键级，也不能破坏原 PDBQT。

### H. Vina/Vinardo 预计算 maps 与标准 AD4

- [ ] **P2-05** 在 Vina/Vinardo 网格区生成并启用 maps；manifest、受体/Box/评分函数哈希齐全。
- [ ] **P2-06** 使用已保存 Vina 或 Vinardo maps 运行；命令使用 maps，结果/报告明确评分协议，不能和另一协议横向混表。
- [ ] **P2-07** 切换“AutoDock4（maps）”；未配置 AutoGrid4 时给出中文配置提示，界面不崩溃。
- [ ] **P2-08** 使用 1DWD 生成标准 AD4 maps 并运行；GPF、GLG、FLD、原子类型 maps、manifest、`ad4_scores.csv` 和 AD4 报告完整。
- [ ] **P2-09** 修改受体、Box、参数文件或任一 map 后重试；旧 maps 失效并阻止运行，标准 Vina 结果不被覆盖。

### I. AD4Zn beta

- [ ] **P2-10** 进入 AD4Zn beta；页面按顺序显示 Zn 位点、TZ 受体、`AD4Zn.dat`、AutoGrid4 兼容性、maps 和运行门禁。
- [ ] **P2-11** AutoGrid4 低于 4.2.7、缺 TZ、非 Zn、多 Zn 或参数文件哈希变化时均 fail closed，错误说明具体门禁。
- [ ] **P2-12** 用合适单核 Zn 案例完成 TZ→maps→Vina→结果/报告；评分明确为 AD4Zn，不与 Vina/标准 AD4 比较。

### J. 水合 AD4

- [ ] **P2-13** 打开“水合 AD4”；页面明确标为 Experimental，并显示单配体、刚性受体、全局 AD4 和独立 maps 的组合边界。
- [ ] **P2-14** 依次完成水合配体准备、W map、运行前检查和 run；步骤状态、产物路径与右侧门禁同步更新。
- [ ] **P2-15** 结果显示 raw AD4 affinity 和强/弱/置换水分类；不得出现“校正 affinity”“dry affinity”或暗示后处理重新评分的字段。
- [ ] **P2-16** 水合报告保留 W 原子守恒、分类规则、输入/maps/工具哈希及“未进行重评分”的边界说明。

## P2：稳定性、兼容与收尾

- [ ] **P2-17** 使用包含中文、空格的项目路径完成一次 PDBQT→Vina→结果→报告；路径显示、命令参数和输出均正确。
- [ ] **P2-18** 打开一个历史项目；缺少新字段时可读取，页面给出默认/迁移结果，不修改已完成 run。
- [ ] **P2-19** 在长任务运行时最小化、切换页面再返回；进度继续，导航不会启动重复后台任务。
- [ ] **P2-20** 强制关闭应用后重开未完成任务；显示可恢复/失败状态，不把半成品标记为完成。
- [ ] **P2-21** 对结果页反复切换“评分 / 运行日志与文件 / 分析报告”、展开/收起 metadata；布局稳定且无持续增长的空白区域。
- [ ] **P2-22** 检查所有可见说明文字；不存在“按你已有的文件选择入口”“每一步都说明……”等写给开发者或 AI 自己看的措辞。
- [ ] **P2-23** 检查所有科学结论；不得声称 docking score 证明真实结合、药效或治疗效果。
- [ ] **P2-24** 查看开发者控制台或日志；正常浏览无未处理异常、React 崩溃、无限重试或持续增长的错误日志。

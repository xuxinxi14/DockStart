# DockStart v1.0.4 用户指南

本指南面向 v1.0.4 Windows x64 Basic/Assisted 试用安装包。截至 2026-10-07，公开下载已提供两种 EXE：Basic 用于已有 PDBQT，Assisted 额外随附原始结构准备工具，也支持已有 PDBQT。下文自动准备说明适用于 Assisted 或用户自行配置的兼容准备环境。下载、文件哈希和验证范围见 [发布说明](release/v1_0_4_release_notes.md)。

第一次使用建议先按 [快速开始](quick_start_v1_0_4.md) 复制内置基础示例，再阅读 [1IEP 真实体系教程](https://xuxinxi14.github.io/DockStart-Docs/docs/part-b/cases/basic-docking-1iep/)。

## 安装和工具检测

安装后先检查软件版本与“工具链”状态。Assisted 随附 AutoDock Vina 1.2.7、独立 CPython 3.11 和 RDKit/Meeko 等准备工具，正常情况下不需要自行安装系统 Python，也不需要手填工具路径。

Basic 同样随附 Vina 与精简后端 Python；已有 PDBQT 的普通对接不需要准备工具。Basic 未包含 RDKit/Meeko，不能把它视为随包支持自动准备。

只有检测失败或你希望使用其他兼容工具时，才在设置中选择实际存在的可执行文件，然后显式重新检测：

- Vina 路径选择 `vina.exe` 文件，不能选择它所在的文件夹。
- preparation Python 选择已安装兼容 RDKit/Meeko 的解释器；它优先于 Assisted 随附的准备环境。
- 后端 runtime 的解析与 preparation 工具链不同，优先使用随附 runtime。
- AutoGrid4 只用于相应 AD4 协议，用户自行安装；普通 Vina/Vinardo 实时对接可以跳过。

工具检测只说明文件和调用能力可用，不能验证输入结构的科学合理性。修复方法见 [工具链修复指南](toolchain_repair_guide.md)。

## 帮助与入门

- 默认启动页是“帮助与入门”；“当前建议”依据实际项目和工具状态给出下一步，读取失败时可刷新或回到项目页。
- 随包提供 19 个离线主题，支持关键词与错误码分类检索。问号先显示简短说明，支持的问号可点击打开详细说明。
- 在线文档和在线搜索通过系统浏览器打开，只有主动点击才联网。浏览器打开失败时可以复制地址。
- 设置页可选择下次启动打开帮助或项目页；不会自动打开历史项目。
- 在线教程独立更新。旧截图会标注版本，具体入口与兼容条件以本页和实际软件为准。

## 1. 创建或打开项目

从帮助页“使用自己的结构”或“项目”入口创建项目。填写项目名称和工作区父目录；保存在独立、可写、空间充足的目录，避免放进软件安装目录。

导入前先确定本次任务：常规第一次对接选择 **全局对接**。评分或局部优化需要已在受体坐标系中定位的配体，不能把独立 PubChem 构象直接当作待评价的结合姿势。

目录主要包含：

```text
project_name/
├─ project.json
├─ raw/          # 原始结构
├─ prepared/     # 准备后的 PDBQT
├─ preparation/  # 准备过程与日志
├─ configs/
├─ runs/         # 每次运行独立记录
├─ results/
├─ reports/
└─ maps/         # 按协议使用的网格
```

同名目录已存在时请换名或打开已有项目。不要手工修改 `project.json` 的版本号或运行状态。

## 2. 导入和准备结构

受体与配体分别按实际文件格式处理，允许 PDBQT 与原始结构混合导入。

| 输入 | 可用格式 | 下一步 |
| --- | --- | --- |
| 受体 PDBQT | `.pdbqt` | 导入后复核结构 |
| 受体原始结构 | `.pdb`、`.cif` | Assisted 尝试准备；CIF 依赖 Gemmi 的受约束桥接 |
| 配体 PDBQT | `.pdbqt` | 导入后复核结构 |
| 配体原始结构 | `.sdf`、`.mol`、单分子 `.mol2` | Assisted 尝试准备 |
| 配体库 | PDBQT/SDF/MOL 多文件、目录或多记录 SDF | 从库导入预览选择有效候选，再建串行队列 |

SMILES、配体 PDB 自动准备、多记录/批量 MOL2 不支持。单配体转换与多记录配体库处理是不同入口；要处理 SDF 全部记录时使用库导入预览，不要依赖单配体转换替你遍历文件。

在“结构获取与转换”中可导入本地文件，也可主动从 RCSB 按 PDB ID/关键词搜索受体，或从 PubChem 按 CID/名称搜索配体。在线候选须明确选择后才写入项目；下载到 `raw/` 的文件仍需准备为 PDBQT。

准备时检查链、质子化、电荷、手性、缺失残基、水、金属与辅因子。Meeko 的模板异常或 alternate location 确认只是记录你选择的处理方式，不能替代结构修复和人工判断。不要盲目确认所有警告。

## 3. 对接箱体

进入“运行工作台”，在同一三维视图中查看受体、配体和对接箱体，设置中心与三轴尺寸，单位为 Å。中心是坐标，尺寸是各轴长度。

依据共晶配体、实验或文献确定搜索区域；“定位到受体”只做几何定位，不识别口袋。真实体系不能套用内置玩具示例的中心和尺寸。过大的区域会增加搜索成本。

## 4. 参数与协议

首次运行保持普通单配体、刚性受体、Vina 全局对接和实时计算。

| 参数 | 含义 |
| --- | --- |
| 搜索彻底程度 `exhaustiveness` | 增加搜索投入，通常增加耗时；不是准确率保证 |
| 输出构象数量 `num_modes` | 最大输出数量，可能返回更少 |
| 能量范围 `energy_range` | 限制相对最佳评分保留的构象范围 |
| CPU | 使用的线程配置，受本机资源限制 |
| 随机种子 `seed` | 与输入、其他参数和工具环境一起记录，便于复现实验条件 |

首次使用不必启用 maps、AutoGrid4、专家开关或实验性协议。评分、局部优化、柔性、批量与共同对接的限制见 [进阶工作流](advanced_workflows.md)。不同评分函数或不同体系的分数不能直接混比。

## 5. 运行前检查与执行

保存参数，重新检查输入 PDBQT、对接箱体、参数、工具和输出目录，处理全部阻塞项后准备并执行 run。

每次运行有独立 `run_id`，常规对接保存：

```text
runs/run_001/
├─ inputs/                # 本次输入快照
├─ config_snapshot.txt
├─ metadata.json
├─ stdout.txt
├─ stderr.txt
├─ log.txt
├─ out.pdbqt
├─ scores.csv
└─ docking_report.md      # 导出后产生
```

运行记录保留工具版本、命令、参数、输入与输出证据、时间和退出码。切换帮助页不会自动取消计算；需要取消时使用运行页的取消入口。取消或失败后保留日志与原 run，修复条件后创建新运行。

## 6. 结果与报告

运行完成后检查终态、构象文件和评分。切换 Mode 查看实际输出，不只看最低分。

- affinity/对接评分单位为 kcal/mol，是当前协议下的计算分值，不能直接解释为药效。
- 表格 RMSD l.b./u.b. 相对本次 Mode 1；Mode 1 为 0/0 是比较基准，不是完美预测。
- 共晶参考 RMSD 是另外的比较，需要同一化学实体和受支持的输入条件。
- `num_modes` 是上限；构象数量较少可能受能量范围或搜索结果限制。
- 普通全局对接导出 CSV 与 Markdown 实验记录。评分/局部优化使用对应评价结果，不能强求生成普通对接的 `out.pdbqt` 和表格。

确认导出的报告引用本次 run，阅读输入、参数、工具版本和科学声明。报告和诊断可能包含本机路径，分享前检查。软件不提供 PDF 报告或自动论文结论。

## 7. 保存、更新和恢复

关闭后通过“打开项目”选择原目录；启动设置不自动打开历史项目。重要项目整体备份，升级前保留一份副本。

Basic/Assisted 共用应用身份。切换档位前正常卸载，保持用户项目在安装目录之外。当前没有自动更新，不会后台安装工具或修改系统 PATH。旧版本是否能打开项目取决于 schema 兼容性，不能仅凭应用版本号保证。

批量历史归档 ZIP 是只读实验记录，不是可恢复运行的完整项目备份。出错时先看 [FAQ](faq.md)；历史阶段性说明保存在 [旧用户指南](history/user_guide_before_v1_0_4_cleanup.md)，不应用作当前教程。

Docking score 仅供结构结合趋势参考，不能替代实验验证。

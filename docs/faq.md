# DockStart v1.0.4 常见问题

适用于 Windows x64 v1.0.4 试用包；下载和哈希见 [发布说明](release/v1_0_4_release_notes.md)，首次使用见 [快速开始](quick_start_v1_0_4.md)。

## 1. Basic 与 Assisted 怎么选？

Basic 面向已有受体/配体 PDBQT 的用户，Assisted 额外随附原始结构准备工具。截至 2026-10-07，v1.0.4 发布页已提供两种 EXE；已有 PDBQT 可选 Basic，需要原始结构准备时选 Assisted。两种档位共用应用身份，不能并行安装。

## 2. 要先安装 Python、Vina、RDKit 或 Meeko 吗？

使用 Basic 或 Assisted 安装版进行已有 PDBQT 的普通 Vina 对接时，不需要自行安装 Python 或 Vina。Assisted 还随附 RDKit/Meeko，Basic 不含这套准备环境。先到工具链页检测，只有检测失败或要替换兼容工具时才配置路径。从源码运行另有资源条件，不能把安装版说明直接套到干净源码。

## 3. 为什么找不到 Vina？

重新检测后，检查安装目录资源是否完整、是否选到了实际 `vina.exe` 文件，以及用户配置路径是否仍存在。系统 PATH 只是其他解析来源，不是安装版的必要前置条件。

保留中文错误码与诊断信息，参见 [工具链修复指南](toolchain_repair_guide.md)。不需要为了重新安装关闭安全软件。

## 4. Meeko/RDKit 不可用，软件还能用吗？

已有有效 receptor/ligand PDBQT 且 Vina 可用时，可以继续普通对接。缺 RDKit/Meeko 影响原始结构准备，不等于所有工作流都不可用。若要替换准备环境，选择兼容 Python，重新检测；软件运行时不会自动安装科学包。

## 5. 现在只能用 PDBQT 吗？MOL2 支持吗？

Vina 的实际输入是 PDBQT，但 Assisted 可以尝试把受体 PDB/CIF、配体 SDF/MOL/单分子 MOL2 准备成 PDBQT。受体与配体可混合原始结构和 PDBQT 导入。

不支持 SMILES 自动准备、配体 PDB 自动准备、多记录/批量 MOL2。多记录 SDF 的库导入有独立预览和逐记录流程，不能与单配体转换混为一谈。

## 6. CIF 是否适合所有结构？

不能保证。CIF 经 Gemmi 受约束桥接为 PDB，再交给 Meeko；多模型、链/残基身份不唯一或不能在传统 PDB 中表达的结构可能被阻止。CIF 的残基控制通过可核查的身份映射处理，不能泛称“所有 CIF 控制都不支持”。具体错误需要按该结构的诊断处理。

## 7. 下载了原始结构为什么还不能运行？

`raw/` 文件不等于 prepared PDBQT。完成适用的准备步骤后，检查生成文件与科学警告，再设置对接箱体和参数。独立 PubChem 构象可用于全局对接输入，但不能直接作为已定位的受体结合姿势进行评分或局部优化。

## 8. 自动准备成功就代表结构正确吗？

不是。需人工检查受体链、质子化、电荷、手性、缺失残基、水、金属、辅因子与配体构象。确认模板异常或删除残基是用户选择的处理记录，不能当作自动修复的科学证明。

## 9. “定位到受体”会自动找到结合口袋吗？

不会，它只做几何定位。对接箱体的位置和尺寸要根据共晶配体、实验或文献确定；三维显示只是检查辅助。Box 单位为 Å，不是 AutoDock4 的网格点数。

## 10. 什么情况下需要 AutoGrid4？

相应 AutoDock4 maps、AD4Zn 或水合协议需要用户自行安装的外部 AutoGrid4；普通 Vina/Vinardo 实时对接可以跳过。它不随 Basic/Assisted 安装包分发。不同 maps 协议和评分语义不能混用。

## 11. 设置输出 9 个构象，为什么更少？

`num_modes` 是上限，实际数量还受能量范围和搜索所得构象限制。结合终态、退出码、日志和输出文件判断，不应仅凭数量少就认定失败。

## 12. Mode 1 的 RMSD 为零，是预测正确了吗？

不是。结果表的 RMSD l.b./u.b. 以本次 Mode 1 为比较基准，所以它自身是 0/0。与共晶参考的 RMSD 是另外一种比较，不能用这两列替代。

## 13. 分数越低是否代表药效越好？

不能。评分受输入结构、评分函数、搜索区域、参数与工具条件影响。它不能证明真实结合、药效、安全性或临床价值，也不能随意跨不同体系或协议比较。

**Docking score 仅供结构结合趋势参考，不能替代实验验证。**

## 14. 3D 查看能做相互作用分析吗？

当前主要用于结构、对接箱体和构象几何查看。它不自动给出 PLIP/ProLIF 的氢键、盐桥、相互作用指纹或口袋预测，也不替代专业建模检查和实验验证。

## 15. 评分、局部优化、批量和共同对接有什么区别？

评分评价已有坐标；局部优化在已有姿势附近优化；串行批量让多个配体分别运行；两个配体共同对接搜索联合构象，只有联合体系的评分，不能拆成成员 affinity。适用条件见 [进阶工作流](advanced_workflows.md)。

## 16. 取消、失败、重开项目怎么处理？

使用运行页取消入口，等待状态结束。失败时保留 `metadata.json`、`stderr.txt`、`log.txt` 和输入快照，修复后创建新运行。关闭后可从项目入口打开原目录；不要删掉历史 run 来掩盖错误，也不要手工改状态为 finished。

## 17. 更新或卸载会影响项目吗？

项目应存放在安装目录之外，重要目录先整体备份。档位共用身份，切换前正常卸载。v1.0.4 EXE 的完整安装/升级/卸载仍待当前产物验收，不能用旧版记录保证所有环境的行为。批量只读 ZIP 不是完整项目备份。

## 18. 软件会上传项目或自动更新吗？

本地计算、准备、项目与诊断在本机完成；主动使用在线结构检索/下载或在线文档时联网。当前没有自动更新，不会后台安装科学包。分享报告前检查绝对路径与研究数据。

## 19. 未签名安装包怎样核对？

只从项目发布页下载，使用 `Get-FileHash -Algorithm SHA256` 对照发布说明。填写 publisher 字段不等于具有签名。哈希不一致或安全工具报告问题时，先核对来源和日志，不要关闭防护来绕过。
